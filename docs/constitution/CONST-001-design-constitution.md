## 1. Purpose

The purpose of this document is to define the permanent visual and emotional identity of the Tania Calligraphy Academy.

This document is the highest authority for visual and interaction design within the Tania Calligraphy Academy.

All future implementations must conform to this constitution.

---

## 2. Brand Identity

Tania is not a technology company.

Tania is not an online store.

Tania is not a startup landing page.

Tania is an academy of Persian calligraphy.

Every design decision must reinforce this identity.

---

## 3. Core Values

Every UI decision must support these values.

- Authenticity
- Elegance
- Calmness
- Respect
- Craftsmanship
- Timelessness
- Precision
- Learning

If a design weakens any of these values, it should be rejected.

---

## 4. Emotional Goal

When a visitor enters the website, they should feel:

> "I have entered a refined artistic space."

Not:

> "I have entered an online shop."

---

## 5. Visual Personality

The interface should communicate:

- Quiet confidence
- Artistic maturity
- Elegance without luxury excess
- Minimalism without emptiness
- Premium quality without showing off

---

## 6. Design Philosophy

The interface should never fight for attention.

Instead, it should quietly guide attention.

The user should discover the content naturally.

---

## 7. Space Philosophy

Whitespace is not empty space.

Whitespace is breathing space.

Every spacing decision must improve readability and calmness.

---

## 8. Composition Philosophy

Layouts should never feel like independent boxes.

Sections should flow naturally into one another.

Visitors should perceive continuity rather than separation.

This principle is especially important in the Hero section, where typography, artist imagery, background, light, and decorative elements should be experienced as a single composition—not as three separate columns.

---

## 9. Motion Philosophy

Motion should resemble the movement of ink on paper.

Animations should be:

- Slow
- Elegant
- Meaningful
- Subtle

Never distracting.

---

## 10. Color Philosophy

Color is used to create atmosphere, not decoration.

Gold should represent dignity, never luxury.

Black should represent ink, not darkness.

Cream should represent paper, not yellow.

---

## 11. Typography Philosophy

Typography must feel composed.

Not compressed.

Not loud.

Every paragraph should feel intentionally placed.

---

## 12. Photography Philosophy

Images should look natural.

Lighting should feel soft.

Nothing should resemble commercial product photography.

---

## 13. UI Behavior

The interface must never pressure the visitor.

- No aggressive popups.
- No visual noise.
- No fake urgency.
- No manipulation.

Respect creates trust.

---

## 14. Things We Explicitly Reject

The following styles are prohibited:

- Startup aesthetics
- Dashboard appearance
- Heavy Glassmorphism
- Neon colors
- Loud gradients
- Gaming effects
- Over-animated interfaces
- Visual clutter
- Decorative elements without purpose
- Trend-driven design without long-term purpose

---

## 15. Success Criterion

If the logo is temporarily removed, the visitor should still recognize the artistic personality of the academy.

If not, the design has failed.

---

## 16. Final Principle

Every component,

every color,

every spacing,

every animation,

must answer one question:

> Does this strengthen the artistic identity of Tania?

If the answer is not clearly **"Yes"**, the decision should be reconsidered.
