# Knowledge Base

This directory contains the project's documentation infrastructure.

It is organized into the following categories:

- **[constitution](./constitution/)** — Foundational principles and governing rules.
- **[adr](./adr/)** — Architecture Decision Records.
- **[missions](./missions/)** — Task and mission specifications.
- **[reports](./reports/)** — Execution and status reports.
- **[standards](./standards/)** — Conventions and standards to be followed.

Each category contains its own `README.md` describing its purpose, and a
generic template to be used when creating new documents in that category.

This structure defines infrastructure only. It does not contain any
project-specific documentation or architectural decisions.
